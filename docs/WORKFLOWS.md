# Workflows

By Geekatplay Studio. All workflows live in `workflows/` and are generated by `tools/build_workflows.py`, which also validates them: links join matching types, required inputs are connected, nodes do not overlap, every node sits inside its group, and titles and note text fit their boxes.

They are saved in the standard ComfyUI workflow format (version 0.4) with plain LiteGraph coordinates, so they open the same way in the classic renderer and in Nodes 2.0.

## Layout

Every workflow reads left to right:

- **Notes** on the far left: what the workflow does, how to use it, which files it needs and where to get them.
- **Numbered groups**, in the order they run.
- **Status** row at the bottom: plan summary, the prompt sent to the model, loader log, LoRA log.

Sampler settings on the KSampler are greyed out because the planner supplies them. To set one by hand, disconnect that input and type a value.

## 1. Text to Image, Auto Router

`geekatplay_text_to_image_auto.json`

`OllamaPromptPlanner` -> `DynamicCheckpointLoader` -> `DynamicLoraStack` -> `CLIPTextEncode` x2 -> `EmptySD3LatentImage` -> `KSampler` -> `VAEDecode` -> `SaveImage`

The planner picks any installed image model. The empty latent adapts to whichever model is loaded.

## 2. Text to Image, MOSS-Image

`geekatplay_text_to_image_moss.json`

The same pipeline pinned with `task_hint = moss_image`, wired like the official MOSS-Image template: `EmptyFlux2LatentImage`, `SkipLayerGuidanceDiTSimple` on layer 22, 25 steps, CFG 2.5, er_sde.

## 3. Image to Image, Auto Router

`geekatplay_image_to_image_auto.json`

`LoadImage` -> `ImageScaleToTotalPixels` (about 1 megapixel, sides in steps of 16) -> `OllamaVisionStylePlanner` and `VAEEncode` -> the shared pipeline.

The vision model sees the picture and sets `denoise`: low to keep the picture, high to restyle it.

## 4. Image to Image, Dual Prompt

`geekatplay_image_dual_prompt.json`

Like workflow 3, using `OllamaVisionDualPlanner`: one prompt says what to look for in the picture, the other what to make from it.

## 5. Text to Video, MiniMax H3

`geekatplay_text_to_video_minimax_h3.json`

`OllamaPromptPlanner` (`task_hint = video`) -> `DynamicCheckpointLoader` + `VAELoader` (audio VAE) -> `MiniMaxH3ImageToVideo` -> `RandomNoise`, `KSamplerSelect`, `BasicScheduler`, `BasicGuider` -> `SamplerCustomAdvanced` -> `VAEDecode` + `VAEDecodeAudio` -> `CreateVideo` -> `SaveVideo`

Wired like the official MiniMax H3 text-to-video template: 20 steps, res_multistep, 768 px short edge, 124 frames (about 5 seconds at 24 fps). The planner writes a prompt that describes both the shots and the sound.

## Changing a workflow

Edit `tools/build_workflows.py` and run:

```bat
python tools/build_workflows.py
```

A workflow is only written if it passes every check.
